Introduction to HTML

HTML is the standard markup language used to build the structure of a web page. It describes how content such as text, images, and links are organized so browsers can display them correctly.

HTML Elements Reference

An HTML element is defined by a start tag, some content, and an end tag. Elements can be nested inside other elements, forming the tree structure of a document.

Common elements include headings (<h1> to <h6>), paragraphs (<p>), links (<a>), images (<img>), and lists (<ul>, <ol>).

Attributes provide additional information about elements and are always specified in the start tag, usually as name/value pairs like name="value".

Every HTML page should include a <!DOCTYPE html> declaration, a <head> section for metadata, and a <body> section for visible content.

Semantic elements such as <header>, <nav>, <main>, <article>, and <footer> help describe the meaning of the content, improving accessibility and SEO.

Forms let users submit data using elements like <input>, <textarea>, <select>, and <button>, combined with a <form> wrapper.

Tables organize tabular data using <table>, <tr>, <th>, and <td> elements.

Good HTML structure makes CSS styling and JavaScript behavior easier to reason about, since selectors and DOM traversal follow the same tree.
